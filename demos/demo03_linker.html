Demo 03 — Pose linker (Stage 5)

3 anchors A/B/C + click do scény. Locomotion picker + cílová pose po dorazu.

Klik na anchor button NEBO klik na podlahu = cíl.

Locomotion

Hranice se vybírají v _pickLocomotion():
• < 5 j → WALK
• < 15 j → Jog
• ≥ 15 j → Sprint

Rychlost se nepočítá z konstanty, ale z rychlosti stojné nohy v body frame (foot tracking). RUN má větší stride a tempo → automaticky vyšší rychlost.

Cílová pose

Anchor může mít then = { status, params }. Po arrival Stickman přepne na ten status místo defaultního STAND. Anchor B sedí, anchor C leží. Klik do podlahy = bez then = STAND.
