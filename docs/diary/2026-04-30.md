## Sezení 10 — Bio/Fyzio Gestures + JUMP + treadmill + Fidget rename + plížení rewrite

### Diskuse

- **Otevření.** Stickman je dobře v polovině F2; chybí JUMP, SWIM, CLIMB, SLEEP, plus „Bio/Fyzio episodické akce" odložené z Sezení 8 a 9 jako Příště bod 4. Uživatel zvolil Bio/Fyzio.

- **`@THINK` Bio/Fyzio.** Strukturovaná analýza: episody jsou třetí druh pohybu (vedle Animations a overlays), drží identitu. Tři architektonické varianty: A) sub-mode v animateStand, B) Status enum, C) `Gestures.js` jako sourozenec Animations. Doporučil jsem C s pose-based keyframes a inline scheduler. Uživatel reframe: **gesta jsou globální OVERLAYS** (jako Fidget/Breathing), spuštěné Poissonovým procesem (ref PocketStory `_poisson` v engine.py), s precondition (= postava v klidu + gesto fyzicky lze provést). 6 gest na seznamu: weightShift, ruce v bok, založené ruce, ruce za hlavou, drbání náhodného místa, protažení.

- **Implementace v1.** PocketStory používá Poisson na per-tick počty událostí (`_poisson(λ, max_yield)` Knuthův algoritmus); pro animace v plynulém čase je správný **inter-arrival = Exponential(λ)** (`-Math.log(U)/λ`). Modul `src/character/Gestures.js` (~280 LOC): `GESTURES` registr s pose-based keyframes (každý gesto = sekvence `{ at, angles, root? }`), `pronePhase()` — wait, jiný gen, `pickKeyframes` + `lerpKeyframes` + smoothstep, `applyGestures(skel, time, state, lambda, stickman)` v render loopu. Per-Stickman state `{ active, nextAt, scheduled }`. Filtr `isResting` (STAND idle nebo SIT). `triggerGesture` pro manual UI buttons (bypassuje Poisson + isResting). Aktivní gesto se přerusí při změně Status (= statusAtStart check) — Pose.capture v setStatus zachytí gesture-modified pose, transition odveze ruce z peak do nové animace.

- **První gesto: armsAkimbo.** Slider Aktivita 0–0.5/s + manuální trigger button. Funguje. Přidal 4 další: `armsFolded`, `armsBehindHead`, `scratchHead`, `stretch`. First-pass odhady úhlů — uživatel iteruje. `stretch` upraven na V-tvar paží (`shoulder.z = 30` přidán k `shoulder.x = 180` pro abdukci do V).

- **weightShift = pelvis tilt.** Diskuse o root deltě v keyframes. Plížení a weightShift potřebují celotělovou dynamiku (úklon, tilt). Rozšířil keyframes o `root: { rx, ry, rz, px, py, pz }` — aditivní delta k primárce (Drift dál točí pelvis, gesto přidá `+8°` tilt + lateralní posun). První verze měla `rz` (pelvis tilt) + `px` (pelvis shift); uživatel: „Naklonění na opačnou stranu a BEZ shiftu, jen úklon" → fix `torso.z` flipnut (lean toward standing leg, ne counter-lean), `root.px` odstraněn. Další iterace: „Odlehčenou nohou může i mírně zakývat vpřed/vzad" → přidány 2 mezikeyframes pro sway. Final: „Celé gesto o ⅓ rychleji a o ⅔ snížit amplitudu" → duration × ⅔, všechny úhly × ⅓. „Dokonalé!"

- **Plán dalšího postupu — `@THINK` Demo03/Demo04.** Uživatel: „Skoky do Demo02 patří, ale plánuj dál: Demo03 = obecné provázání dvou póz (P1 → [W/S/J] → P2 podle vzdálenosti). Demo04 = interakce s objekty (židle, postel, klika)". `@THINK` analýza: pose-link je atom všeho (sbírání/těžba/boj/crafting všechny dekomponují na lokomoce + interakční pose + cyklus + exit). PoseSequence třída v character/, distance metric + locomotion picker (walk < 5j < jog < 15j < sprint), turn-to phase. Interactable třída v new `src/world/` s `approachPose` + `usePose` + IK pin points. Brain v F3 = scheduler nad PoseSequence. F4+ = specializace. Pořadí: JUMP → Demo03 → SWIM/CLIMB/SLEEP → Demo04 → F3 Akvárium → F4 hra. Zapsáno do IDEAS jako roadmap.

- **Posun postavy.** Uživatel: „Posun podlahy by byl u Demo02 fajn." První iterace: `forwardSpeed` (j/s) v params, akumulovat `worldPos.z`, aplikovat na `skel.rootPosition`. Třetí iterace: „O opačný vektor rychlost" → flip sign na worldPos.z. Tlačítko „Domů" odebráno (postava se nikdy nepohybuje, takže nemá smysl).

- **Foot tracking.** Uživatel: „Rychlost posunu nesedí. Walk: rychlost chodidla stojné nohy = -rychlost posunu podlahy". Reformulace: dynamicky počítat rychlost z planted ankle Z velocity v body frame. První varianta: track planted ankle, na step transition skip delta (= 1 frame jerk). Uživatel: „Pořád škube". Druhá: extrapolace z lastBodyDz — pořád škube. Třetí podle uživatelova návrhu: „1. Zjisti všechny opěrné body, 2. Najdi rychlost a směr nejrychlejšího, 3. Pohybuj podlahou opačně". Implementace: per frame all supports → max |dz| s continuity check. Stále škube (= late swing dipy do tolerance dávají max |dz| s opačným směrem).

- **History-based pick.** Insight: PASSIVE leg drží na floor (history rostoucí); swing dipy mají krátkou history. Změna: pick joint s **nejdelší consecutive history**. Walk/Jog/Sprint/Crawl/Sneak fungují perfektně. Plížení škube (= PASSIVE leg ankle drží history forever ale stojí, případně active joint má wrong direction). Pokus o fix přes hybrid history+max|dz| → rozbije walk → návrat k pure history-based, plížení odloženo (TODO F2.4).

### Rozhodnutí

- **Bio/Fyzio = global overlay s Poisson schedulerem**, NE Status sub-mode. Sourozenec Fidget/Breathing v render pipeline. Pose-based keyframes s root deltou pro celotělové gesta (weightShift). 7 gest implementovaných v this iteraci.
- **Poisson inter-arrival** přes Exponential(λ) — `-log(rand)/λ`. Lambda 0–0.5/s slider. Trigger jen když isResting (STAND idle / SIT). Manual button triggers bypassují.
- **Root delta v keyframes** — aditivní k primárce. Umožňuje gesta s celotělovým motion (úklon při weightShift) bez kolize s Drift.
- **Status.JUMP** = jeden `animateJump` se 5 fázemi a 3 presety v `JUMP_PRESETS`. `params._airborne` flag pro snap-to-floor skip během AIR.

- **Treadmill** postava centrovaná, podlaha posouvá texture offset opačně. Foot tracking dynamicky z planted joint Z velocity. Pure history-based pick (= longest consecutive support frames), s extrapolací z lastBodyDz když žádný support s history ≥ 2.
- **`forwardSpeed` smazán** z DEFAULTS_WALK/RUN_PRESETS/CRAWL/PRONE/SNEAK (magic numbers nahrazeny dynamickým výpočtem). Ponechán jen v JUMP_PRESETS jako manual override.
- **Rename Neklid → Fidget** kvůli globálnímu izomorfismu (= všechny názvy souborů a identifikátory AJ). „Neklid" zachován jako doménový pojem v prose docs + UI label.
- **PRONE = asymetrický 4-fázový cyklus** (REACH/PUSH/PASSIVE/drag) per noha podle biomechanické reference. Diagonální páry. Nohy hotové; paže + spine + pelvis rotation čekají na F2.4 polish.

#### Algoritmus floor scroll (final)
```js
// Identifikuj all supports (joints na minY ± tolerance):
for (const j of skel.joints) {
    if (j.worldPosition.y > minY + SUPPORT_TOL) continue;
    currentSupports.set(j.name, j.worldPosition.z);
    newHistory.set(j.name, (supportHistory.get(j.name) ?? 0) + 1);
}
// Pick joint s nejdelší history (= true planted)
let bestName = null, bestHistory = 1;
for (const [name, hist] of newHistory) {
    if (hist > bestHistory) { bestHistory = hist; bestName = name; }
}
// Použij jeho world Z deltu
if (bestName) {
    const dz = currentSupports.get(bestName) - prevSupports.get(bestName);
    worldPos.z -= dz;
    lastBodyDz = dz;
} else {
    worldPos.z -= lastBodyDz;  // extrapoluj z poslední validní
}
```
